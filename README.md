# OrderFlow – B2B Order Management System

A full-stack B2B Order Management System developed using React, Node.js, Express.js and Microsoft SQL Server.

## Project Overview

OrderFlow is a web-based platform designed to simplify business-to-business product ordering, inventory management, order processing and invoice generation.

## Key Features

- User Authentication
- Role-Based Access Control (Admin and Customer)
- Product Management
- Inventory and Stock Management
- Shopping Cart
- Order Management
- Invoice Management
- REST API Integration
- SQL Server Database Integration
- Input Validation and Error Handling

## Technology Stack
